# 记忆净化仪 (Clear Cache 工具) 使用指南

记忆净化仪是一个专用的后台工具页面，旨在清理本地持久化缓存（`localStorage`）中残留的玩家各类通关进度、错误惩罚、以及特效观看记录。它主要解决由于动态后缀（如时间戳 `updated`）导致正常手段难以精确清除数据的问题。

## 一、页面访问

该页面不需要固定的应用入口，仅支持通过修改浏览器地址栏中的 URL 与 `query` 参数进行直接访问。

**基础 URL 路由**：`/questions/clearCache`
**完整示例方式**：`http://[域名或本地环境]/questions/clearCache?type=qa&step=1&user=testUser`

---

## 二、支持的 Query 参数说明

访问净化仪时，可以通过以下参数自由组合匹配所需清理的指定缓存。支持多维度精确匹配与部分层级放宽清除（缺省参数匹配该类别下所有记录）。

### `type` (必传)

指定需要清除的数据类型。支持以下三种：

- **`qa`**：答题进度残留（即用户在某层的通关态、已答防重复信息等历史）。
- **`penalty`**：答题错误时附加锁死倒计时与错误计数。
- **`rankUp`**：特定级别的“升级庆典动画”观看标记（避免单账号无限触发）。

<br>

### 其他属性参数 (选传)

所有的过滤参数当**传值**时，会精确匹配对应坐标下的记忆碎片；当**不传值（留空）**时，对应纬度的条件被放宽，将涵盖范围内的所有记录。

| 参数   | 适用 type       | 描述                           | 留空时的行为                                               |
| :----- | :-------------- | :----------------------------- | :--------------------------------------------------------- |
| `step` | `qa`, `penalty` | 关卡的层级数字（例如 1、10）。 | 不筛选层级，匹配指定的 `type` 及 `user` 的**所有层级**数据 |
| `user` | 所有 type       | 用户的全局唯一 ID 或账号标志。 | **匹配该类别/层级下的所有用户记录**                        |
| `rank` | `rankUp`        | 进阶级别的标识数字。           | 匹配所有升阶级数的动画观看记录                             |

## 三、常用场景与 URL 示例

### 1. 答题进度类 (`type=qa`)

- **清除某用户某一层关卡的答题记录**
  `/questions/clearCache?type=qa&step=1&user=testUser`

  > 常用于重置某题让指定玩家重新作答。

- **清除所有测试用户第一关的进度记录**
  `/questions/clearCache?type=qa&step=1`

  > 题目或逻辑变动时，重置所有人的这关进度缓存。

- **清除某特定用户的全部关卡进度**
  `/questions/clearCache?type=qa&user=testUser`
  > 整体重置某个用户的全盘答题轨迹。

### 2. 惩罚禁锢类 (`type=penalty`)

- **解封某玩家单独在第三关的冷却反噬**
  `/questions/clearCache?type=penalty&step=3&user=testUser`

- **解封某玩家所有的错误冷却记录**
  `/questions/clearCache?type=penalty&user=testUser`

- **清除所有用户的惩罚状态**
  `/questions/clearCache?type=penalty`
  > 用于全局调整或集中解除测试期间的账号死锁情况。

### 3. 等级升华印迹 (`type=rankUp`)

- **让某个用户再次观看到刚升 2 级的全屏特效**
  `/questions/clearCache?type=rankUp&user=testUser&rank=2`

- **重置该用户产生的所有升级特效防重复标记**
  `/questions/clearCache?type=rankUp&user=testUser`

## 四、操作指南

1. **查验与比对**：按照 URL 规则组合并打开页面后，顶部会提示你的查询目标。下方卡片列表将列出当前本机捕获的所有带目标前缀标记的真实缓存值。如果列表为空，则代表并无该对象的存在。
2. **单独净化**：向左滑动目标卡片，露出红色的【净化】按钮，点击即可删掉单条缓存记录。
3. **全部净化**：确认列表下挂信息全部都要舍弃无误后，点击底部【✦ 全部净化 ✦】，即一次性清除展示的所有对应类型缓存。
4. **返回重置**：完成后观察左侧状态气泡，点击底部【返回现实】则路由回到上一级，再次浏览页面以检查清除是否如预期。
